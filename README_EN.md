A DSH plugin that tracks token usage statistics.

## Features

- **Today's Token Usage**: Real-time statistics by model
- **7-Day Trend Chart**: Stacked trend visualization
- **Cache Hit Rate**: Track cache efficiency
- **Summary Badge**: Optional header badge for quick access

## Installation

```bash
dsh plugin --profile web add dsh-token-usage-xc
```

## Configuration

Configure via DSH settings panel.

## Requirements

- Node.js >= 18
- DSH >= 0.1.0-rc.2
